# Easy Sandbox organization profile

This repository is the GitHub organization profile for [Easy Sandbox](https://github.com/Easy-Sandbox). The public landing page is [`profile/README.md`](profile/README.md).

| Repository | What it is |
|:--|:--|
| [easy-sandbox](https://github.com/Easy-Sandbox/easy-sandbox) | `ebx` command-line tool |
| [python-sdk](https://github.com/Easy-Sandbox/python-sdk) | Python client and in-sandbox server |
| [awesome-templates](https://github.com/Easy-Sandbox/awesome-templates) | Template catalog |

The CLI is installed with npm (`@easy-sandbox/cli`). The Python packages are `easy-sandbox` and `easy-sandbox-server`. There is no `serverless-sandbox` package and no `sbox` command.
