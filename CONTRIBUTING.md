# Contributing to Agent Sandbox

Thank you for contributing. Each repository has its own guide. Open the pull request on the repository that owns the change.

| Repository | What changes belong there | Guide |
|:--|:--|:--|
| [agent-sandbox](https://github.com/alibaba-agent-sandbox/agent-sandbox) | `abx` CLI (`@agent-sandbox/cli`) | [CONTRIBUTING.md](https://github.com/alibaba-agent-sandbox/agent-sandbox/blob/main/.github/CONTRIBUTING.md) |
| [python-sdk](https://github.com/alibaba-agent-sandbox/python-sdk) | `agent-sandbox` and `agent-sandbox-server` | [CONTRIBUTING.md](https://github.com/alibaba-agent-sandbox/python-sdk/blob/main/.github/CONTRIBUTING.md) |
| [nodejs-sdk](https://github.com/alibaba-agent-sandbox/nodejs-sdk) | `@agent-sandbox/sdk` | [README](https://github.com/alibaba-agent-sandbox/nodejs-sdk/blob/main/README.md) (this repository does not yet ship its own CONTRIBUTING.md; use [Conventional Commits](https://www.conventionalcommits.org/) and the Apache-2.0 license) |
| [awesome-templates](https://github.com/alibaba-agent-sandbox/awesome-templates) | Sandbox templates and `awesome-templates.yaml` | [CONTRIBUTING.md](https://github.com/alibaba-agent-sandbox/awesome-templates/blob/main/CONTRIBUTING.md) |
| [awesome-providers](https://github.com/alibaba-agent-sandbox/awesome-providers) | Provider plugins and `awesome-providers.yaml` | [CONTRIBUTING.md](https://github.com/alibaba-agent-sandbox/awesome-providers/blob/main/CONTRIBUTING.md) |

## Reporting issues

- Use the issue templates on the repository that owns the code
- For security vulnerabilities, see [SECURITY.md](SECURITY.md)
- Questions about `abx` can go to [Discussions](https://github.com/alibaba-agent-sandbox/agent-sandbox/discussions)

## License

By contributing, you agree that your contributions will be licensed under the license of the repository you change (Apache-2.0 for the CLI, Python SDK, Node.js SDK, and providers; MIT for awesome-templates).
